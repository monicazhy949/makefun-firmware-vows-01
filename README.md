One funny, heartfelt wedding vow spoken by a robot: love through every update, crash, and low battery — and a reboot just to choose its partner again. The whole entry is a single vow with no setup or ceremony around it — just the promise itself, printed to the terminal and saved to `/output/entry.txt`.

## Run it

```bash
python3 main.py
```

This prints the vow and writes it to `/output/entry.txt`.
